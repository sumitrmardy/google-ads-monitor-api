# Pricing Model

The [Google Ads Monitor](https://apify.com/sumitr_mardy/google-ads-monitor) charges per event:

- **`ad`**: $0.0012 on Free tier down to $0.0007 on Gold tier per ad returned (from $0.70 per 1,000). Ad copy, OCR, and format metadata included.
- **`target_checked`**: $0.01 per target checked in monitor mode.
- In monitor mode, only genuinely new ads (judged by `firstShown` after the previous check) are returned and charged.

See the live rates on the [Pricing page](https://apify.com/sumitr_mardy/google-ads-monitor/pricing).
